# gostty

Go bindings for [libghostty-vt](https://github.com/ghostty-org/ghostty), the
terminal emulation core extracted from [Ghostty](https://ghostty.org). The
bindings are generated by [zigo](https://github.com/ironpark/zigo).

```go
import "github.com/ironpark/gostty"

term, _ := gostty.NewTerminal(80, 24)
defer term.Close()

stream, _ := term.NewStream(0)
defer stream.Close() // before term: see "Lifetimes" below

stream.Feed([]byte("\x1b[1;1Hhello\x1b[2;1H\x1b[31mworld"))

screen, _ := term.PlainString()
fmt.Println(string(screen)) // hello\nworld
```

## Layout

| Path | Contents |
|---|---|
| `*_gen.go` | The public Go package, at the module root. Generated; do not edit. |
| `internal/raw/` | Generated cgo call layer. Not part of the supported API. |
| `zig/build.zig` | Build definition: ghostty dependency, zigo wiring, link fixups. |
| `zig/src/bindings.zig` | What is exposed to Go. |
| `zig/src/root.zig` | The few declarations ghostty does not provide and zigo needs. |
| `zig/zigo/` | Generated metadata (`semantic.json`, `errors.lock.json`). |
| `docs/zigo-findings.md` | zigo gaps found by building this, and their status. |

The public package sits at the module root, so `gostty_*_gen.go` names are
reserved for the generator: a hand-written file with one of those names would be
overwritten on the next `make generate`.

Most of libghostty-vt is bound directly: `Terminal` is ghostty's own type and
its methods become Go methods without a wrapper. `zig/src/root.zig` only adds a
constructor pair, an `std.Io` value, field accessors and a release function.

## Building

Requires Zig 0.16 and Go 1.24+. `make` drives both toolchains; `make help`
lists every target.

```bash
make build      # build the native binding library
make test       # build, then run the Go tests
make generate   # regenerate the Go tree from zig/src/bindings.zig
make example    # run the example program
```

`zig build go` writes the `*_gen.go` files at the root, plus `internal/raw/` and
`zig/zigo/`. Both the
generated Go and the metadata are committed, so consumers only need a Go
toolchain — but the native archive is not, so a fresh checkout must run
`zig build` once before `go build` will link.

## Lifetimes

- Every handle has an idempotent `Close`. Calls after `Close` return
  `ErrInvalidHandle` rather than touching freed memory.
- **A `Stream` must be closed before the `Terminal` it feeds.** ghostty's
  handler reaches through the terminal for its allocator when it tears down, so
  the reverse order is a use-after-free. Nothing enforces this for you.

## Status

Early. The bound surface is a useful slice of libghostty-vt — terminal state,
VT stream parsing, cursor, unicode width — not all of it. SIMD is currently
disabled; see `docs/zigo-findings.md`.
